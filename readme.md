The dataset for automobile part image classification is a specialized dataset for 50 categories of common automobile core parts. It covers a total of 9239 images and is in the standard directory structure with CSV annotation format. The dataset is divided into train, validation, and test sets according to the conventions of "train / val / test". The images are in JPG format.
